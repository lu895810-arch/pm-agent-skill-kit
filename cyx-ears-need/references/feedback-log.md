# 反馈台账（feedback-log）

本文件记录 `cyx-ears-need` 的规则演化。每轮用户反馈按 SKILL.md 第 10 章 的三步判定后追加一行。

**列含义**

| 列 | 说明 |
|---|---|
| 日期 | 反馈发生的日期 |
| 用户原话（节选） | 尽量保留原话，便于回溯语境 |
| 类别 | A 章节结构 / B 需求写法 / C 编号与台账 / D 范围与优先级 / E 判断质量 / F 视觉与呈现 / G 命名与触发 |
| 落点 | 改到了哪个文件的哪一节 |
| 处置 | 新增 / 强化 / 高频升级 |

**规矩**

- 同一类别出现 ≥2 次并标「高频」的，回 SKILL.md 把该条从建议升级为强约束（加粗、加机检、或前移到自查清单）。
- 个案不入本台账。
- 规则被推翻时，追加一条「规则回退」，**不是删掉原条目**。
