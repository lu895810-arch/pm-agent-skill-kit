# 去 AI 味 · 图示文字产出标准（Buddy 版）

画图时的解释文字——标题、副标题、图注（sec-cap）、旁注（note）、结论表、页脚——走 Lulu 的「去 AI 味」标准。这一篇只管文字；图本身的干净度另有 §4 反模式管。

## 为什么要有这条

Lulu 要的是「说人话、能给依据、读着不别扭」的交付物。AI 生成的文字常带一类没有实指的填充词和对称排比，读起来像机器在汇报而不是人在讲。去掉它们，信息密度和可信度都上来。

## 禁词清单（命中即改）

| 类别 | 禁用 | 改成 |
|---|---|---|
| 空标签 | 赋能、闭环、生态化、深度赋能、抓手、组合拳、底座、护城河、产品哲学、颗粒度、对齐、拉通、沉淀、反哺、飞轮、矩阵、范式、底座 | 说清它具体是什么：赋能→「帮 X 做到 Y」；闭环→「机制 / 回路」；护城河→「壁垒 / 竞争优势」；底座→「基础」 |
| 读法动词 | 赋能、助力、驱动、打造、构筑 | 直接写动作 |
| 对称排比 | 「不仅……而且……」「一方面……另一方面……」 | 拆成两句实话说 |
| 过渡填充 | 综上所述、值得注意的是、众所周知、事实上、可以说 | 直接接下一句 |
| 效率填充 | 「一次说清」「一目了然」「轻松搞定」「一键……」（非产品原名时） | 删掉，或换成具体动作 |
| emoji | 默认不带 | Lulu 明确要才加 |

> 「闭环」在禁用词里——任何「计费闭环」「数据闭环」「业务闭环」都改成「机制 / 回路 / 能力」等实指词。「底座」「护城河」「产品哲学」也是 buzzword，同样改掉。

## 五条硬标准（写完自测）

1. **通俗易懂**：行业词、缩写第一次出现给白话定义（是什么 + 为什么叫这名）。拿同义词当解释算没解释。
2. **专业严谨**：判断有依据、数据有出处、口径划清；不夸大、不含糊、不用「大概 / 可能 / 相对较好」糊过去。
3. **叙事逻辑闭环**：结论有推导、推导有事实、事实有来源；段按「是什么 → 为什么 → 所以怎么办」推进，前后不打架。
4. **段落衔接流畅**：段与段有承接，不是条目堆叠；读时不用回头找主语、不被跳脱转折绊住。
5. **去 AI 味**：不写上面禁词，不写营销腔，不写「首先 / 其次 / 最后」三段套。

## 自测两问

- 这段话念给不懂这行的人听，他能不能用自己的话复述？不能 → 重写。
- 删掉这句废话，意思会不会变？不会 → 删。

## 落到图上的具体位

- **标题（H1）**：说清「比什么、谁和谁」，不堆形容词。
- **副标题（sub）**：一句话交代数据源 / 范围，判断给依据。
- **图注（sec-cap）**：讲这张图「看什么」，不是「这是一张图」。
- **旁注（note）**：给判断依据，不写「综上所述」。
- **结论表**：结论列写白话（「已经做到 / 还没做」），不写规格书式分号短句。
- **页脚**：标清数据口径与来源，不写营销腔。

## 命名：标签跟来源文档的原词

对比类图表里的维度名和标签（结论表首列、象限轴名、图例项），直接用被对比文档里已有的章节用词，不要换成自己顺手造的同义词。

- 例：来源文档写「1.1 核心定位」，表首列就写「核心定位」，不写「一句话定位」；来源写「模块组织逻辑」，就不要改成「切分方式」。
- 判据：审阅者拿着这个标签回原文档里搜，能不能直接搜到？搜不到 → 换成原词。
- 只有来源文档自己没给词条时（如「八维能力评分」这类本次新造的评估维度），才允许自拟名，并在图注里交代评分口径。

## 评分 / 数据类图注的口径提醒

柱状图、雷达图这类相对评分，凡是依据文档覆盖度而非实测的，必须在图注或页脚标注「非实测、相对判断」，并说明每个分数的依据来源。不标口径就拿去立项评审，是给审阅者埋雷。
